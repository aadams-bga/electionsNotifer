Installtion guide

You can add this site to your device's app folder or homescreen like any other app. Installing gives you an icon on your home screen and, on iPhone and iPad, it's required for push notifications to work.

iPhone & iPad (Safari or Chrome)

  1. Open this site in Safari or Chrome.
  2. Tap the Share button (the square with an arrow).
  3. Scroll down and tap "Add to Home Screen," then Add.
  4. Open the app from the new home-screen icon, then turn on push notifications from the sign-up or manage page.

Apple only allows push notifications like this for installed apps. Push enabled in a regular browser tab won't work on iPhone/iPad. Devices running iOS installed before March 2023 (iOS 16.4) may not work with this type of application framework.

Android (Most browsers)

  1. Open this site in Chrome or Firefox.
  2. Tap the ⋮ menu icon, then "Install app" in Chrome and "Add to Home screen" in Firefox. Other browsers may vary.

Push notifications also work in the regular browser on Android.

Computer (Chrome / Edge / Firefox)

  1. Look for the install icon at the right end of the address bar (a screen with a down arrow or similar) and click it.

Push notifications also work in the regular browser on desktop (Chrome, Edge, and Firefox). Desktop Firefox doesn't offer an install option, but you can add a shortcut to the site to your computer's taskbar.

Do I need to install it?

If you would like push notifications or if you want to keep a shortcut on your device, you should install the application. This is required for push notifications on iOS. Email alerts never require the app.
